## 一、整体架构（30 秒版）

```
        ┌─────────────┐         MQTT / REST           ┌──────────────────────┐
 设备   │  ESP32 BMS  │ ───────────────────────────▶  │  后端 (Python)        │
 (电池)  │  固件采集    │                               │  app.py + 一堆 .py    │
        └─────────────┘                               └───────────┬──────────┘
              ▲                                                │ SocketIO / REST
              │ 命令下发                                        │
              │                                                ▼
        ┌─────────────┐                               ┌──────────────────────┐
        │  后端把数据  │ ◀──────────────────────────  │  前端 (浏览器网页)     │
        │  存进 SQLite │     读 /api/* 与实时推送      │  index.html + app.js  │
        └─────────────┘                               │  + style.css          │
                                                  └──────────────────────┘
```

一句话：**固件采集电池数据 → 后端接收并存库 → 网页通过接口/实时推送把数据画成图表和按钮**。
两条数据链路：① 华为云 **IoTDA**（`iotda_client.py`，主链路）；② **自建 Mosquitto broker**(1883) 经 `iotda_mqtt_bridge.py` 桥接（ECS docker 三件套，供手机/App 订阅）。

## 三、前端文件详解

> 前端 = 你打开网页看到的界面与交互逻辑。改样式看 `style.css`，改交互/图表/命令看 `app.js`，改页面结构看 `templates/`。

### 3.1 `templates/`（页面骨架 / HTML）

| 文件 | 是什么 | 改它干嘛 / 注意 |
|---|---|---|
| `index.html` | 主控制台。包含 7 个视图（`data-view="overview/cells/trends/control/alarms/reports/settings"`）的全部 HTML 结构、桌面导航、移动端底 Tab、弹窗、`<canvas>` 图表容器。静态资源用 `?v=` 缓存爆破。**改完务必 bump `?v=`**。 | 增删页面区块、改按钮文字、调布局结构。HTML 由 Flask 渲染（`{{ url_for('static', ...) }}`），改完**刷新即生效**（已设 `TEMPLATES_AUTO_RELOAD`）。 |
| `login.html` | 登录页，**独立模板、内联样式**。不受 `index.html` 的 `?v=` 控制。 | 改登录界面外观。改完需**硬刷新**（Ctrl/Cmd+Shift+R），因为浏览器/Cloudflare 可能缓存旧 HTML。已重写移动端为流体宽度 + 安全区（`viewport-fit=cover`、触控目标 ≥50px）。 |

### 3.2 `static/style.css`（设计系统）

不是普通样式表，而是一套**设计令牌（Design Tokens）+ 双主题**系统：

- **主题变量**：通过 CSS 自定义属性（`--bg-primary`、`--text-secondary`、`--accent-cyan`、`--border-color` 等）定义。暗色为默认，日光主题通过 `:root` 或 `data-theme` 覆盖同一批变量 → 换肤只需改一套变量。
- **令牌类别**：背景（`--bg-primary/card/secondary`）、文字（`--text-primary/secondary/muted`）、强调色（`--accent-cyan/blue/green/red/yellow`）、边框（`--border-color/active/strong`）、圆角（`--radius/radius-lg`）、阴影（`--shadow-card/shadow-lg`）、轨道（`--track`）。
- **响应式**：移动端用 `@media` 把桌面侧边导航换成底部 Tab（`mobile-nav`），KPI 字号递减，横向滚动条细化。
- **无障碍**：`:focus-visible` 焦点环、可点击卡片的键盘焦点样式。
- **防抖关键改动（2026-08-12）**：
  - `.views{ ...; scrollbar-gutter:stable }` —— 永久预留滚动条空间，**消除"数据变化时滚动条闪现导致整页横移抖动"**（整页抖动的主因）。
  - `app.js` 的 `_setupCanvas()` 改为**仅在尺寸真正变化时才重置画布缓冲**，避免每帧清空导致的闪烁/重排。
  - `.chart-body{ position:relative; ... }`（保留 `min-height` 给出的确定性高度，画布 `width/height:100%` 填充）。

### 3.3 `static/app.js`（前端大脑，~6000 行）

按职责分成若干"模块"（都是同文件内的函数/对象，非独立文件）：

| 模块 / 关键函数 | 职责 |
|---|---|
| `ViewRouter`（对象） | **企业级导航**：事件委托统一接管所有带 `data-view` 的元素（导航项、可点击 KPI 卡片）。点击/键盘 Enter/Space → `navigate(view)`。渐进增强：跳过已有内联 `onclick` 的旧导航，避免重复触发。 |
| `switchView(v)` | 切换视图：class 切换 + `requestAnimationFrame` 内图表 `resize()` + 异步拉取设置页数据。**轻量，不阻塞点击**。 |
| `initSocket()` / SocketIO 绑定 | 建立实时连接，监听 `bms_data` 推送。 |
| `handleBmsData(input)` | **实时数据总入口**。归一化 3 种来源（SocketIO / `/api/status` 平铺 / 旧 `{ok,data}`）→ 串数动态适配 → 延迟计算 → 去重 → 严格二值在线判定 → 分发到 KPI/3D/表格/曲线/告警。 |
| `_gateRun(key, ms, fn)` | **节流闸门**：KPI(200ms)/3D(200ms)/表格(300ms)/移动端(500ms)。防止高频数据刷屏卡顿。 |
| `updateKPI(p)` | 刷新总电压/电流/SOC/SOH/功率/循环次数、CRC 完整性横幅、缓存徽章。数值用 `tabular-nums` 防位数抖动。 |
| `pushMainChart(p)` / `loadMainChartHistory(range)` | 实时曲线与历史曲线（总电压/最高温/电流）。`update("none")` 关动画。`historyChart`/`trendChart`/`sohTrendChart`/`reportChart` 同理。 |
| `renderCellTable(cells)` | 单体电芯数据表（电压/压差/内阻/温差/SOC/状态）。仅数据变化时整表重建。 |
| `B3D`（对象） + `renderBattery3D()` + `setBattery3DView(v)` | **3D 电池组视图（Pack）**：自研轻量 3D 引擎（透视 + 光照 + 拖拽旋转 + 点击聚焦高亮 + 正面/侧面/俯视/等距四视角）。`ensureBattery3DDOM()` 惰性构建 DOM。 |
| `updateMobileViz()` | 移动端电芯电压条形总览。 |
| 命令函数：`startCharging/stopCharging/startDischarging/stopDischarging/rebootDevice/emergencyStop/sendCommand/toggleBalance/openBalanceModal/...` | 对应控制页按钮，走 `POST /api/cmd`。 |
| 设置页：`loadRulesConfig/saveRules/loadPushConfig/savePush/loadAuditLog/...` | 联动规则、告警推送、操作审计的配置与展示。 |

## 四、后端文件详解（Python）

> 后端 = 网页背后真正干活的程序：收数据、存库、提供接口、实时推送、下发命令。

| 文件 | 职责 / 关键说明 |
|---|---|
| `app.py` | **主程序/入口**。Flask + SocketIO + eventlet。定义路由（`/`、`/login`、`/logout`）与全部 REST API，向前端实时推送。模块级引用 `RuleEngine_`/`AlertPusher`（已在顶部 `from iotda_rules import ...` / `from alert_push import ...` 修复过 NameError）。**改它必须重启进程**。含 OTA 服务路由（`/api/ota/version.json`、`/api/ota/firmware.bin`、`/api/ota/download/<filename>`、`/api/ota/info`、`/api/ota/publish`）。 |
| `database.py` | **SQLite 模块**（`bms_history.db`）。历史数据写入与查询，含串数动态适配、`query_history(start,end)` 任意区间查询（覆盖原 LIMIT 50000 截断问题）、`aggregate_history()` 服务端按范围桶聚合（配合 `/api/history?agg=1`）。 |
| `iotda_client.py` | **华为云 IoTDA 客户端**（主链路）。`requests` + 手工 HMAC-SHA256 签名查影子、下发异步命令，再经 SocketIO 推前端。 |
| `iotda_mqtt_bridge.py` | **IoTDA → 本地 Mosquitto 桥接**（ECS docker 三件套之一，`bms-bridge` 容器运行它）。从 IoTDA 拉设备数据写入自建 broker(1883)，手机/App 直接订阅。 |
| `mqtt_client.py` | **MQTT 客户端**（连接本地 Mosquitto，订阅 BMS 主题，写库并推送）。 |
| `alert_push.py` | **告警推送**：企业微信 webhook / Server酱 / PushPlus，含限流去重。配置在 `dashboard.env`，全空则禁用。 |
| `iotda_rules.py` | **联动规则引擎**：影子数据 → 自动命令 + 告警（低电量保护、过压禁充、过温全断）。配置见 `rules_config.json` / `dashboard.env`。 |
| `utils.py` | **公共工具**：`safe_int`/`safe_float` 等"坏值兜底、绝不抛异常"的数值解析，根治畸形数据崩溃。 |

| `manage_users.py` | 多用户账号管理（admin/operator 等角色，`/api/me` 返回角色供前端门控）。 |

## 五、REST API 完整参考

> 基址：`https://<你的域名>/`（本地 `http://127.0.0.1:5000`）。除 `/login`、`/api/status`（部分）外多数需登录态（Cookie/Session）。

| 路径 | 方法 | 参数 / 说明 | 返回 |
|---|---|---|---|
| `/` | GET | 主控制台页面（渲染 `index.html`）。响应头 `Cache-Control: no-store` 防 HTML 缓存。 | HTML |
| `/login` | POST | `{password}`。校验 `dashboard.env` 的 `BMS_DASH_PASSWORD` 或用户表。**per-IP 失败 5 次锁 10 分钟**（看门狗旧版误锁已修复）。 | 重定向/登录页 |
| `/logout` | GET | 注销。 | 重定向登录页 |
| `/api/status` | GET | 平铺当前状态。字段：`pack_v`(mV)、`current`(mA,+充/-放)、`soc`/`soh`(%)、`cells[]`(mV)、`v_max`/`v_min`、`temp_max`/`temp_min`、`fault`(位掩码)、`balance_mask`、`cycle_count`、`charge_mos`/`discharge_mos`/`balance_on`、`series_num`、`device_online`、`data_source`、`crc_ok`、`data_age_ms`、`last_event_time_ms` 等。 | JSON |
| `POST /api/cmd` | POST | `{cmd, paras}`。指令白名单（`ALLOWED_CMDS`）：`set_charge`/`set_discharge`/`set_balance`/`set_relay`/`clear_alarm`/`restart`/`get_info`/`ota_check`/`reset_params`/`switch_battery` 等。 | JSON(结果) |
| `POST /api/params` | POST | `{key, value}` 下发设备参数（如串数）。 | JSON |
| `/api/history` | GET | `?agg=1` 服务端聚合（按范围桶）；否则返回原始行。前端三图均 `agg ? agg : 客户端聚合` 优雅降级。 | JSON(行/桶) |
| `/api/export.csv` | GET | `?start=&end=`(YYYY-MM-DD) 任意区间导出 CSV。 | CSV |
| `/api/report` | GET | `quarterly`(YYYY-Qn 或 YYYY-MM→所在季)/`yearly`(YYYY)；年报按月分桶(12 点)，季报按天(~92 点)。 | JSON/文件 |
| `/api/me` | GET | 返回 `role`/`is_admin`，前端据之门控 admin 编辑。 | JSON |
| `/api/ota/version.json` | GET | **匿名**（ESP32 无登录态）。返回 `{version, url, size, build_time}`，url 按请求 Host 拼完整地址。 | JSON |
| `/api/ota/firmware.bin` | GET | **匿名**。下载当前发布固件（`firmware/bms.bin`），流式传输。 | bin |
| `/api/ota/download/<filename>` | GET | **匿名**。下载指定历史版本（`firmware/` 下，防目录穿越）。 | bin |
| `/api/ota/info` | GET | 调试信息：服务器固件版本/大小/路径/是否存在。 | JSON |
| `/api/ota/publish` | POST | **admin-only + CSRF**（2026-08-16 新增）：multipart 上传 `file=.bin` + `version`，落盘 `firmware/bms.bin` 并写 `version.json`，校验 100KB~20MB。 | JSON |
| `/api/rules` | GET/POST | GET 拉联动规则；POST `saveRules()` 保存。 | JSON |
| `/api/push_config` | GET/POST | GET 拉告警推送配置；POST 保存。**密钥脱敏(`***`)**，前端留空发 `__keep__` 保持原值。 | JSON |
| `/api/audit_log` | GET | `?limit=&cmd=` 操作审计日志。 | JSON |
| `/api/healthz` | GET | **免登录健康检查端点**（看门狗新版用它，避免误锁 IP）。 | 200/401/403/5xx |

> **单位约定（重要）**：电压 mV、电流 mA（+充/−放）、温度 0.1℃、SOC/SOH %。前端除展示外一律按此换算。

## 六、SQLite 数据模型

- **库文件**：`bms_history.db`（实时数据落盘处）。
- **主历史表**（由 `database.py` 维护）：每行 ≈ 一次采样，列含 `recv_time`(epoch)、`pack_v`、`current`、`temp_max`/`temp_min`、`soc`、`soh`、`cells`(多列或序列化)、`fault`、`balance_mask`、`cycle_count`、`device_online`、`data_source` 等。
- **写入**：MQTT/IoTDA 收到即写；前端实时曲线只走内存缓冲，**不**依赖历史表。
- **查询**：`query_history(start,end)` 支持任意 epoch 区间；`aggregate_history()` 按范围分桶（供后端聚合优化）。
- **真实数据缺口（非 bug）**：电压自 ~2026-08-06 起停止上报（`pack_v` 恒 0），电流仍在记录；DB 行数万级，末条 `recv_time≈2026-08-10`。1h/6h/24h 电压全空（曲线断），7d 左段（08-04~08-06）有电压。

## 九、数据流与实时推送机制

1. **设备上报**：ESP32 → 华为云 IoTDA（主链路）。
2. **后端接收**：`iotda_client.py` 轮询影子 → `database.py` 写库 → SocketIO 推前端；同时 `iotda_mqtt_bridge.py` 桥接到自建 Mosquitto(1883) 供手机/App 订阅。
3. **前端展示**：`app.js` 监听推送 → `handleBmsData` 分发 → KPI/曲线/3D/表格。历史查询走 `/api/history`；指令下发走 `POST /api/cmd`。
4. **命令下发**：网页按钮 → `app.js` → `POST /api/cmd` → `app.py` → `iotda_client` → 设备执行。
5. **去重**：`handleBmsData` 用 `last_event_time_ms`(→timestamp→本地时间) 三级兜底生成 key，避免 SocketIO+轮询双通道重复 push。
6. **历史刷新**：原"每 2s 随消息全量重拉 7 天(1 万行)"已移除，改为 **60s 定时**；高频更新用 `update("none")` 跳过动画 → 不再卡顿。
7. **性能闸门**：实时绘制走 `_gateRun` 节流 + 去重 + 可见性门控（`_elVisible`），与点击处理完全解耦 → 无点击卡顿根因。

## 十一、常见"坑"与排错

- **改 `static/app.js`/`style.css` 后页面没变？** 浏览器缓存。改完 bump `index.html` 里对应 `?v=`，**刷新（F5）**即可（无需重启 Flask）。
- **改 `app.py`/`database.py` 等 Python 后没生效？** 必须**重启后端进程**（代码不热加载）。
- **登录页样式没变？** `login.html` 独立模板，需**硬刷新**。
- **登录被锁"失败次数过多"？** 旧看门狗用 `password=bms123` 做健康检查触发 per-IP 锁定。已改免登录健康检查；改 `.ps1` 后**重启看门狗**生效（约 600s 自动过期）。
- **历史曲线 7 天卡？** 服务端聚合 `?agg=1` 需重启看门狗；旧进程回原始行，前端优雅降级。
- **网页"整页抖动"？** 已通过 `scrollbar-gutter:stable` + 固定图表容器高度 + 画布按需重设尺寸修复（2026-08-12）。
- **页面"看起来空按钮"？** 经全量审计，所有 `onclick` 函数均存在；唯一曾有的真死链（总览"SOC-SOH 趋势"卡片）已改为可点击视图链接。
- **登录验证脚本注意**：用脚本反复 `127.0.0.1` 登录会把自己锁死（本机 IP 命中锁定）。验证请求头带唯一 `X-Forwarded-For: 203.0.113.x` 可避开。
