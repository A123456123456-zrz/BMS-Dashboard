## 1. 项目根目录总览

```
D:\esp32project\BMS\BMS System\
├── CMakeLists.txt            # ESP-IDF 顶层构建脚本（引入 components + main）
├── sdkconfig                 # 当前编译配置（ESP-IDF 生成，一般不动）
├── sdkconfig.defaults        # 编译默认配置（可加自定义编译选项）
├── partitions.csv            # Flash 分区表（含 OTA A/B 双分区）
├── dependencies.lock         # 组件依赖锁文件（ESP-IDF 托管组件）
├── .gitignore                # Git 忽略规则
├── main/                     # 固件入口（app_main，初始化+启任务）
├── components/               # 固件组件（核心，分 4 个子组件）
├── docs/                     # 技术文档（10 份，见 §3）
├── 说明书/                    # ★ 本系列说明书（v1.0 新增）
├── tools/                    # 工具：网页 Dashboard + 华为云对接
├── build/                    # 编译产物（固件 bms.bin 在这里）
└── managed_components/       # ESP-IDF 托管组件（自动下载，勿手改）
```

## 2. 固件层 components/（每个文件的作用）

### 2.1 `components/bms_config/` —— 全局配置（改参数优先看这里）

| 文件 | 作用 | 要改什么 |
|------|------|----------|
| `include/bms_config.h` | **核心配置**：硬件使能开关、电池参数、保护阈值、任务栈、SOC 参数、MQTT/OTA 地址 | 见 §4 参数速查 |
| `include/bms_pinmap.h` | **引脚映射**：所有 GPIO 定义 | **改接线只改这一个文件**，全工程自动生效 |
| `include/bms_types.h` | 公共数据类型（采集/故障/状态结构体） | 新增数据字段时改 |
| `include/bms_errno.h` | 错误码定义（BMS_OK/BMS_ERR_*） | 一般不动 |

### 2.2 `components/bms_app/` —— 应用层（业务逻辑与算法）

| 文件 | 作用 |
|------|------|
| `app_tasks.c` | 任务调度：创建 10 个 FreeRTOS 任务（采集/保护/SOC/通信/均衡/OLED/SD/OTA/报警/看门狗） |
| `app_soc.c` | SOC/SOH 估算：AEKF（二阶 RC 等效电路）+ 安时积分 + OCV 三次多项式查表，v_meas=0 时只做积分预测 |
| `app_protection.c` | 保护逻辑：过压/欠压/过流/过温（含 dT/dt 热失控预警）/压差，带迟滞恢复 |
| `app_balance.c` | 均衡控制：电压差/容量差/定时策略（被动均衡，阈值在 bms_config.h） |
| `app_charge.c` | 充电管理（CC/CV） |
| `app_alarm.c` | 声光报警驱动（蜂鸣器 PWM + LED） |
| `app_ota.c` | OTA 升级：HTTP 下载 + A/B 分区 + 防回滚 |
| `app_key_ui.c` | 按键交互 + OLED 菜单（BOOT 键短按翻页/长按复位/双击切换） |
| `test/` | 组件测试 |

### 2.3 `components/bms_middleware/` —— 中间层（通信/存储/状态机）

| 文件 | 作用 |
|------|------|
| `sys_mqtt.c` | 华为云 IoTDA MQTT：属性上报/命令处理/参数下发/影子，HMAC 动态鉴权 + 认证失败自愈重连（s_need_reauth 循环）；**2026-08-09 高可靠加固：上报追加 `crc32` 字段（CRC8+CRC32 双重完整性校验）** |
| `sys_wifi.c` | WiFi 连接/重连 |
| `sys_params.c` | 参数持久化（NVS，v9 版本） |
| `sys_data.c` | 全局数据共享（采集数据缓存） |
| `sys_fsm.c` | 状态机（含热失控锁定/解除） |
| `sys_storage.c` | Flash/NVS 底层存储 |
| `sys_offline_cache.c` | 断网数据缓存与补传（SPIFFS） |
| `sys_can.c` | CAN 报文组帧 |
| `sys_filter.c` | 数据滤波（电流均值滤波等） |
| `sys_config_portal.c` | 配网门户（Web 配网） |

### 2.4 `components/bms_bsp/` —— 板级驱动（硬件外设）

| 文件 | 作用 |
|------|------|
| `bsp_ltc6804.c` | LTC6804 电压采集 AFE 驱动（SPI2，**多芯片方案A**：16S=2片/24S=2片/32S=3片，共享 SPI2+独立片选，串号全局拼接、均衡掩码按 12 位拆分） |
| `bsp_insulation.c` | **绝缘检测驱动**（2026-08-09 新增：不平衡电桥法，Rp/Rn 解算 + 100Ω/V 判定；**链路已贯通**：固件上报 insulationRp/Rn/OhmPerV → 物模型 3 属性 → 后端透传 → 前端 KPI 卡片，硬件接线后置 1 即启用） |
| `bsp_current.c` | 电流 ADC 采样（ADC1_CH0 → mA 换算） |
| `bsp_relay.c` | 充/放电继电器控制（低电平吸合） |
| `bsp_temp.c` | 温度采集（NTC） |
| `bsp_oled.c` | OLED 显示（I2C 0x3C） |
| `bsp_buzzer.c` / `bsp_led.c` | 报警指示 |
| `bsp_can.c` | MCP2515 CAN 通信 |
| `bsp_sd.c` | SD 卡黑匣子记录 |
| `bsp_bq34z100.c` | BQ34Z100 独立电量计 |
| `bsp_active_balance.c` | 主动均衡 PWM 驱动 |
| `bsp_button.c` | 按键 |

## 4. 参数速查：改参数去哪里改（重点）

### 4.1 固件参数 —— 统一在 `components/bms_config/include/bms_config.h`

| 类别 | 宏 | 当前值 | 含义/怎么调 |
|------|----|--------|-------------|
| 硬件开关 | `HW_ENABLE_LTC6804` | 0 | **LTC6804 AFE**：驱动保留（`#if` 包裹），C1 仿制板不用；需用时改 1 |
| | `HW_ENABLE_BQ76952` | **1** | **电压采集 AFE（BQ76952，I2C 0x08）**：当前方案，电压/电流/温度/均衡/FET 全部由它提供 |
| 串数 | `BMS_CELL_SERIES_NUM` | 16 | **默认串联数**（2026-09-07 由 6 改为 16，C1 仿制板 BQ76952 16S）；**运行时可由网页/MQTT/Modbus 下发 1~16 切换**（NVS 持久化，总压基准联动） |
| | `BMS_HW_MAX_SERIES_NUM` | 16 | **硬件上限**（BQ76952 原生 3~16S；串数下发/POST 自检的校验上限） |
| | `BMS_MAX_CELL_SERIES_NUM` | 32 | **编译期上限**（数组/缓冲/均衡掩码上限，运行时串数 ≤ 硬件上限 ≤ 本值） |
| | `LTC6804_CELL_NUM` | 12 | 单颗 AFE 芯片最大串数（硬件固定 12，勿改；仅 LTC6804 方案用） |
| | `HW_ENABLE_CURRENT_SENSE` | 1 | 电流采样开关（**2026-08-25 起数据源=BQ76952 库仑计 CC2，替代 INA181 ADC**） |
| | `HW_ENABLE_OLED` / `HW_ENABLE_LED` | 1 / 1 | **OLED 已恢复**（2026-08-25：SH1106 @ 0x3C，与 BQ76952 0x08 **并联同一 I2C 总线**，地址不冲突；I2C 总线由 bsp_bq76952_init 建立，bsp_oled_init 不再重复初始化）；LED=红/绿/白三色灯（2026-09-07 新增白灯 GPIO38 板载 RGB，替代 WS2812 方案） |

### 4.2 引脚 —— 统一在 `components/bms_config/include/bms_pinmap.h`

> 2026-08-25 更新：主控改为 **ESP32-S3 最小系统板**（可用 GPIO0~21 + 35~48，G22~34 未引出），
> PCB 仿 LibreSolar **BMS-C1**（BQ76952 + TWAI CAN + RS485 + 双 LED + **OLED**（0x3C 并联 I2C）+ **蜂鸣器**（GPIO11，2026-08-25 新增），无继电器/INA181/SD/BQ34Z100）。

| 宏 | GPIO | 用途 |
|----|------|------|
| `PIN_I2C_SDA/SCL` | 8/9 | BQ76952 AFE（I2C0，地址 0x08；与 C1 v0.4 及原工程一致） |
| `PIN_BQ76952_WAKE` | -1 | **禁用**：C1 无 WAKE(LD) 接线，依赖 I2C 访问自唤醒 |
| `PIN_CAN_TX/RX` | 5/4 | TWAI CAN（SN65HVD230 收发器，与 C1 一致，500kbps） |
| `PIN_CAN_STB` | 48 | SN65HVD230 待机控制（低=正常，与 C1 一致） |
| `PIN_RS485_TX/RX` | 14/21 | RS485（UART1 via GPIO matrix，Modbus RTU；DE/RE 短接共用 GPIO47） |
| `PIN_RS485_DE_RE` | 47 | RS485 方向控制（DE/RE 短接，高=发送，低=接收） |
| `PIN_LED_RED/GREEN/WHITE` | 1/2/38 | 三色状态灯（红=保护/严重, 绿=正常, 白=板载 RGB 共阳 低亮高灭；预警慢闪/充电恒亮；2026-09-07 由双灯扩为三灯） |
| `PIN_BUTTON_USER` | 0 | BOOT 键（短按翻页/长按 3s 复位/双击切换/长按 5s 配网） |
| `PIN_SW_PWR` | 13 | SW_PWR 电源键（仿 C1，高有效，长按 3s 关功率；按键接 3.3V，2026-08-25 新增） |
| `PIN_BUZZER` | 11 | 有源蜂鸣器（高电平响；需 NPN 三极管驱动，2026-08-25 新增） |

**S3 约束（勿占用）**：GPIO0/3/45/46 = strapping；GPIO19/20 = USB-Serial-JTAG（COM6 烧录口）；
GPIO43/44 = UART0（RX0/TX0 调试）；GPIO39~42 = JTAG。
**空闲可用**：GPIO6、7、15、16、17、18、35、36、37。（占用：0/1/2/4/5/8/9/11/12/13/14/21/38/47/48；strapping 3/45/46；USB 19/20；UART0 43/44；JTAG 39~42 保留）

> ⚠️ 改引脚只改此文件；接线前确认负载电平与上电状态（strapping 引脚上电电平）。

### 6.1 重新烧录自动重新配网（2026-08-13 新增）

- **行为**：用 `idf.py flash` **串口重新烧录新固件**后，设备启动时检测到固件变更，自动**清除 WiFi 配置并进入 AP 配网模式**（连接 `BMS_Config` 热点 → 192.168.4.1 重新配网）。
- **判定机制**（2026-08-13 B7 修复后）：
  - **OTA 升级标记**（`ota_upgraded` NVS key）：OTA 成功重启前由 `app_ota.c` 显式写入 → 新固件启动读到标记 → **保留** WiFi 配置并消费标记。
  - **编译指纹**（`BMS_FIRMWARE_VERSION` + 编译日期时间，每次编译必变，存 `reflash_fp` NVS key）：无 OTA 标记时比对——指纹不同（或首次运行本固件但 NVS 已有旧 WiFi 配置）→ 串口重新烧录 → 清配置进配网。
  - **不用分区状态判断**：串口烧录会把 otadata 清空（`ota_data_initial.bin` 全 0xFF），bootloader 首启在 `set_actual_ota_seq` 中把运行分区写为 `VALID`——与正常重启后状态完全相同，分区状态**无法**区分"烧录后首启"与"正常重启"，故改走显式标记 + 编译指纹。
- **开关**：`components/bms_config/include/bms_config.h` 中 `BMS_REPROVISION_ON_REFLASH`（默认 `1`=开，`0`=关闭恢复旧行为）。
- **实现**：`sys_wifi_check_reflash()`（`sys_wifi.c`，启动时在 STA/AP 决策前调用）；指纹/标记存取 `sys_params_get/set_reflash_fp()`、`sys_params_set/is/clear_ota_upgraded()`（`sys_params.c`）。
- **注意**：只重新编译不烧录 / 烧录相同 .bin / 正常重启 → 指纹不变，不触发。首次上电（无配置无指纹）→ 不动作（本就未配网）。
- **配网页预填默认 WiFi（2026-08-13）**：配网页（192.168.4.1）的 SSID/密码输入框预填 `bms_config.h` 的 `BMS_WIFI_SSID`/`BMS_WIFI_PASS`（出厂默认 WiFi），SSID 下方显示"当前已存"（NVS 实际值）。重新烧录进配网后直接点保存即用默认 WiFi，换 WiFi 在页面改。
