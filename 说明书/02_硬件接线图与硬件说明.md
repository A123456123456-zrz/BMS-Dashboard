## 2. 电源系统（C1 仿制板，2026-08-25 更新）

> ⚠️ **S3 最小系统板的 5V 和 3.3V 两个电源引脚都必须由外部稳定供电**（用户实测：只接 5V 电压不稳、无法工作）。
> 因此 C1 板需输出 **5V + 3.3V 两路**，分别接到 S3 板 5V 脚和 3.3V 脚。
> C1 原设计 LMR38010 只出 3.3V —— 仿制时**改 FB 分压输出 5.4V（R28 82k→110k、R31 35.7k→24.9k，1% 0603，2026-08-26 原理图坐标匹配确认 + 压降补偿）**，再**加一级 3.3V 电源（TPS563200 同步 Buck，3A；备选 TO-252 AMS1117-3.3）** 出 3.3V。
> ⚠️ **发热评估（2026-08-26）**：5V→3.3V 压差 1.7V，ESP32-S3 WiFi TX 峰值 355mA 时 PD=0.6W。SOT-223 AMS1117（θJA=150°C/W）温升 90°C、结温 115°C，**有热关断风险，勿用 SOT-223 硬扛**。采用 TPS563200 同步 Buck（4.5~17V 输入、3A、效率 ~90%，几乎不发热）；若坚持 LDO 至少换 TO-252（θJA=125°C/W）并大面积铺铜。

### 2.1 方式①：电池供电（正常运行）

```
电池组 BAT+ ──▶ LMR38010 Buck(改输出 5.4V) ──▶ D1(SS14) ──▶ 5V(5.1V) ──▶ S3 板 5V 脚
      │              │                        │
      │              └──▶ 3.3V 同步 Buck(TPS563200) ──▶ 3.3V ──▶ S3 板 3.3V 脚
      │                                                        │
      └──▶ BQ76952 REGIN（REG18 LDO 供 FET 驱动等）      C1 板 3.3V 网络(OLED/收发器/LED) ──┘ 共用
```

- 日常运行用这种：**只接电池，不插 USB**，整机单电源。
- S3 板 **5V 脚**和 **3.3V 脚**分别由 C1 板两路输出供给（3.3V 与 C1 板 3.3V 网络共轨）。

### 2.2 方式②：USB 只调试不供电（推荐，2026-08-26 改）

**USB-C 座只接 D+/D− 数据线，VBUS 断开不接** —— USB 只做烧录/日志，完全不供电，从根本上避免 USB 与电池 5V 打架：

```
USB-C 座:  D+ ──► GPIO20(USB_D+)
           D− ──► GPIO19(USB_D−)
           VBUS ── 断开(不接) ✂️   ← 不供电,只烧录/日志
           GND ──► 共地
```

- 烧录、看日志、调 OLED/蜂鸣器/WiFi 时用这种：**USB 只调试，整机仍由电池供电**。
- ⚠️ 无电池时 **BQ76952 不工作**（REGIN 没电），电压/电流/SOC 为 0，属正常现象；主控侧功能（OLED/按键/蜂鸣器/WiFi）需电池供电才能测。
- **注意**：USB 不供电后，S3 板 5V/3.3V 必须由电池侧提供（见 2.3），否则 S3 板无电无法烧录/调试 —— 调试时需接电池。

### 2.3 供电与防打架（USB 不供电 + 3.3V 轨二极管 OR）

**USB 不供电（VBUS 断开）后，5V 轨只有电池一路，天然不打架；但 S3 板 5V 脚有电池电时板载 LDO 仍会输出 3.3V，与外部 TPS563200 的 3.3V 打架 —— 所以 3.3V 轨必须加二极管 OR：**

```
电池 ──► LMR38010(改5.4V) ──► D1(SS14) ──► 5V 汇合点 ──► S3 板 5V 脚
 反馈: R28→110k / R31→24.9k        │
                                    └──► TPS563200(3.6V) ──► D3(SS14) ──► S3 板 3.3V 脚
                                         反馈: R1→374k / R2→100k             ▲
                                                              S3 板板载 LDO(3.3V)┘
GND ───────────────────────────────────────────────────────────► 共地(必须)
```

- **5V 轨**：USB VBUS 断开 → 只有电池一路（LMR38010 5.4V → D1 → 汇合点 5.1V → S3 板 5V 脚），无需双源 OR。
- **3.3V 轨防打架（2026-08-26）**：S3 板 5V 脚有电 → 板载 LDO 出 3.3V；外部 TPS563200 也出 3.3V → **必须加 D3(SS14) 隔离**，并把 **TPS563200 输出调到 3.6V**（R1→374k、R2→100k），经 D3 压降 0.3V 后正好 3.3V —— 两源电压相等、被 D3 隔开，互灌电流 ≈ 0，不打架。
- **压降补偿（2026-08-26）**：LMR38010 输出调到 **5.4V**（R28→110k、R31→24.9k），经 D1(SS14) 后汇合点 **5.1V**，S3 板 5V 脚满足（4.5~5.5V）。
- 这样**任意接法都安全**：只接电池全功能运行、USB 只调试不供电（电池供电）、两者都插也不打架，5V/3.3V 两轨始终有电。

### 2.4 注意事项

- **共地必须保证**：电池负极（BAT−）与 S3 板 GND 通过排针连通，否则 I2C/GPIO 电平参考不一致。
- **5V 与 3.3V 两轨都必须接**：5V 与 3.3V 都进 S3 板电源脚，3.3V 同时给 C1 板器件（BQ76952 逻辑侧、OLED、CAN/RS485 收发器、LED）；功率部分（FET 驱动）由 BQ76952 REG18 自持，无需外部电源。
- 原继电器方案已废弃（RELAY=1 语义改为 BQ76952 FET 控制），无继电器线圈，无需续流二极管。

### 2.5 板间排针接口（S3 最小系统板 ↔ C1 PCB，整体算一块板）

> 结构：仿 C1 PCB 上放置 **2×N 排母座**，S3 最小系统板的排针直接插入，电源与全部信号经排针互联，物理上组合为一块整机板。

| 排针网络 | S3 板引脚 | 说明 |
|----------|-----------|------|
| **5V** | 5V 脚 | C1 板 LMR38010 输出(改 5.4V, 经 D1 SS14 压降后 5.1V) → S3 板 5V;USB 只调试不供电(VBUS 断开) |
| **3.3V** | 3.3V 脚 | C1 板 3.3V 同步 Buck(TPS563200, 由 5V 降压)输出 → S3 板 3.3V(双轨都必须接) |
| **GND** | GND | 与 C1 板 BAT− 共地(必须) |
| I2C | GPIO8(SDA)/GPIO9(SCL) | BQ76952 + OLED 0x3C 并联 |
| BQ76952 ALERT | **GPIO12** | 事件中断(开漏+10k上拉, 高有效; 2026-08-25 新增, C1 为 GPIO2) |
| CAN | GPIO5(TX)/GPIO4(RX)/GPIO48(STB) | SN65HVD230 |
| RS485 | GPIO14(TX)/GPIO21(RX)/GPIO47(DE/RE) | SN65HVD75 短接 |
| LED | GPIO1(红)/GPIO2(绿)/GPIO38(白板载RGB) | 三色状态灯（2026-09-07） |
| 蜂鸣器 | GPIO11 | 有源蜂鸣器(经 NPN 三极管) |
| SW_PWR 电源键 | **GPIO13** | 长按 3s 关功率(仿 C1; 按键接 3.3V, 高有效, 2026-08-25 新增) |
| BOOT 键 | GPIO0 | 板上自带,短按翻页等 |
| 烧录 | GPIO19/20(USB-JTAG) | COM6,不可占用 |

> 其余 S3 板引脚(11~15/18/21/35~42/47/48)为空闲,排母座可一并引出备用。

## 3. 电压采集 LTC6804-2（当前未接，接线后启用）

> 状态：`HW_ENABLE_LTC6804=0` → 单体电压/SOC/温度显示 0，网页有"未接线"提示横幅。
> **接线后把宏改 1 并重新烧录固件**，数据即自动恢复。

```
┌─────────────── ESP32-S3 SPI2 ───────────────┐
│ GPIO12 (MOSI) ──▶ LTC6804-2 SDI            │
│ GPIO13 (MISO) ◀── LTC6804-2 SDO            │
│ GPIO14 (SCK)  ──▶ LTC6804-2 SCKI           │
│ GPIO27 (CS)   ──▶ LTC6804-2 CSBI (片选)    │
└────────────────────────────────────────────┘
         │
         ▼
LTC6804-2 ── C1..C12 ──▶ 电池组各串联节点 (6S: 用 C1~C6, 串数任意 1~12)
LTC6804-2 ── VREF/REG ──▶ 滤波电容 (参考数据手册)
```

- **BQ76952 单芯片 3~16 串**（当前方案）；若日后换 LTC6804 方案：16S/24S/32S 用**多芯片方案（方案A：多颗 LTC6804-2 共享 SPI2 + 独立片选，32S=3 颗 12+12+8）**，驱动保留可编译（`HW_ENABLE_LTC6804=1` 启用）
- 片选引脚：芯片0=GPIO27、芯片1=GPIO2、芯片2=GPIO6（`PIN_LTC6804_CS/CS1/CS2`，避开 GPIO26 继电器与 GPIO25 SPIHD）
- ⚠️ 本项目 1~32S 采用**方案A（多片选 SPI），不是 isoSPI 菊花链**；菊花链（方案B，需 LTC6820）仅 48S+ 才评估
- SPI 速率 1MHz（`LTC6804_SPI_HZ`），电压分辨率 100μV（`LTC6804_VLSB_UV`）
- 温度采集：LTC6804 的 GPIO 通道可接 NTC 热敏电阻（10kΩ，当前从芯片0读取）

## 4. 电流采样（已接）

```
电池组负极母线 ──▶ 电流传感器(霍尔/分流) ──▶ 负载/充电器
                        │
                        └──▶ GPIO1 (ADC1_CH0)  ← 传感器输出电压 0~3.3V
```

- 换算逻辑在 `bsp_current.c`（ADC 读数 → mA）
- 电流滤波：`CURRENT_FILTER_SAMPLES=16` 点均值滤波
- 方向约定：**正=充电，负=放电**（实测 -6056mA 表示 6A 放电）

## 5. 继电器与功率回路（未接）

```
电池组正极 ──▶ [充电继电器 GPIO10] ──▶ 充电器
        │
        ├──▶ [放电继电器 GPIO26] ──▶ 负载
        └──▶ 电压采样(分压) ──▶ 电流传感器
```

- **继电器低电平有效**：GPIO 输出低 → 继电器吸合
- ⚠️ 历史坑：充电继电器原 GPIO25 在 S3 上是 SPIHD（SPI Flash 专用）不可用，已改 **GPIO10**
- **2026-08-10 安全加固**：ESP32 复位瞬间到 init 执行之间 GPIO 默认输出低电平，继电器会短暂吸合；软件已尽力（init 后立即断开），根治需在**驱动管栅极加外部上拉电阻**（约几毛钱/路）
- 驱动建议：ULN2003 达林顿管或光耦隔离 + 续流二极管

## 6. OLED 显示（已接）

```
GPIO8 (SDA) ──▶ OLED (0x3C) SDA
GPIO9 (SCL) ──▶ OLED SCL
```

## 10. 接线后启用流程（以 BQ76952 为例）

1. 按 §3 接好 BQ76952（16S 用 VC1~VC16 + 分流电阻；默认串数 16，运行时可经网页下发 1~16 切换，`BMS_CELL_SERIES_NUM` 仅定默认值）
2. 确认 `bms_config.h`：`HW_ENABLE_BQ76952=1`、`HW_ENABLE_CURRENT_SENSE=1`、`HW_ENABLE_TWAI=1`（C1 仿制板默认全部为 1）
3. 重新编译烧录：`idf.py -p COM6 flash`
4. 重启 Dashboard / 刷新网页 → 电压/电流/SOC/温度实时显示（日志见 `bq76952 init ok`）
5. 接线后按 `功能安全达标方案.md` 做安全验证
