# BMS 电池管理系统 —— 项目总览与架构说明

- 版本: v1.0 | 日期: 2026-08-09 | 作者: BMS Team
- 适用代码: `D:\esp32project\BMS\BMS System`（固件 + 网页服务 + 云端）

---

## 1. 项目是什么

一套 **1~32 串自适应的磷酸铁锂（LFP）电池组智能管理系统**（设计目标：软件算法与网页全链路自适应任意串数，当前按 C1 仿制板 16S 默认，运行时可下发 1~16S 切换），由三层组成：

```
┌────────────────────────────────────────────────────────────┐
│ 硬件层:  ESP32-S3 主控 + BQ76952 电压采集AFE(I2C, 3~16S)      │
│          + 电流/温度传感器 + OLED 显示 + 继电器 + (可选 CAN/SD/均衡)      │
│ 扩展:    (历史备选) LTC6804 多芯片 SPI 方案已由 BQ76952 取代      │
├────────────────────────────────────────────────────────────┤
│ 固件层:  ESP-IDF (FreeRTOS) 多任务 BMS 控制程序               │
│          (采集→保护→SOC/SOH→均衡→充电管理→MQTT上报→OTA)        │
├────────────────────────────────────────────────────────────┤
│ 云端层:  华为云 IoTDA（设备接入 / 物模型 / 影子 / 命令下发）      │
├────────────────────────────────────────────────────────────┤
│ 服务层:  tools/dashboard 本地网页服务（Flask+SocketIO+SQLite） │
│          + Cloudflare 隧道对外发布(公网可访问)                 │
└────────────────────────────────────────────────────────────┘
```

核心数据链路：

```
ESP32固件 ──MQTT上报──▶ 华为云IoTDA ──影子轮询──▶ dashboard/app.py
                                                        │
   网页(浏览器) ◀──WebSocket推送 / REST API 轮询──────────┘
```

## 2. 项目定位与技术栈

| 维度 | 选型 | 说明 |
|------|------|------|
| 主控 | ESP32-S3 最小系统板 | 双核 240MHz，WiFi+BLE，性价比高；可用 GPIO0~21+35~48 |
| 系统 | ESP-IDF v5.2.7 + FreeRTOS | 官方 SDK，C 语言 |
| 电压采集 | **BQ76952**（I2C 0x08） | TI 3~16 串 AFE，±mV 级，内置均衡/库仑计/FET 驱动；**当前方案**（LTC6804 驱动保留，#if 包裹） |
| 电流采样 | **BQ76952 库仑计 CC2**（内置分流电阻） | 已启用，实时上报（替代 INA181 ADC） |
| 温度采集 | BQ76952 TS1~TS3（ADCIN 模式） | 3 路温度通道 |
| 显示 | **三色 LED** (红 GPIO1 / 绿 GPIO2 / 白 GPIO38 板载 RGB 共阳) | 分级报警指示（绿=正常, 白慢闪=预警, 红快闪=保护, 红+白常亮=严重, 白恒亮=充电; 2026-09-07 由双灯扩为三灯） |
| 功率控制 | **BQ76952 CHG/DSG FET**（FET_CONTROL 子命令） | 由 AFE 直接驱动 MOS（替代继电器 GPIO） |
| CAN | **TWAI（ESP32-S3 内置）+ SN65HVD230** | 标准帧 11-bit ID，500kbps（替代 MCP2515） |
| RS485 | UART1 + SN65HVD75/MAX3485 | Modbus RTU 从站，9600-8N1 |
| 云平台 | 华为云 IoTDA（标准版，cn-south-4） | MQTT 接入 + 影子 + 物模型 |
| 网页服务 | Flask 3.0 + SocketIO + eventlet + SQLite | 本地 5000 端口 |
| 公网 | Cloudflare Tunnel (bms0605.dpdns.org) | 域名对外发布 |
| 语言 | C（固件）/ Python（服务）/ JS+HTML（前端） | — |

## 3. 架构分层详解

### 3.1 固件分层（components/）

严格五层：`main → App(应用) → Middleware(中间层) → BSP(板级驱动) → Driver(ESP-IDF)`

| 层 | 目录 | 职责 | 主要文件 |
|----|------|------|----------|
| 入口 | main/ | 初始化 + 任务启动 | main.c（app_system_init + app_tasks_start） |
| App | components/bms_app | 业务逻辑/算法/任务调度 | app_tasks.c / app_soc.c / app_protection.c / app_balance.c / app_charge.c / app_alarm.c / app_ota.c / app_key_ui.c |
| 中间层 | components/bms_middleware | 通信/存储/状态机/参数 | sys_mqtt.c / sys_params.c / sys_wifi.c / sys_data.c / sys_fsm.c / sys_storage.c / sys_offline_cache.c / sys_can.c / sys_filter.c / sys_config_portal.c |
| BSP | components/bms_bsp | 板级外设驱动 | bsp_ltc6804.c / bsp_current.c / bsp_relay.c / bsp_temp.c / bsp_oled.c / bsp_buzzer.c / bsp_led.c / bsp_can.c / bsp_sd.c / bsp_bq34z100.c / bsp_active_balance.c / bsp_button.c |
| 配置 | components/bms_config | 全局配置/引脚/类型/错误码 | bms_config.h / bms_pinmap.h / bms_types.h / bms_errno.h |

**FreeRTOS 任务清单（10 个）**：

| 任务 | 优先级 | 栈 | 周期 | 职责 |
|------|-------|-----|------|------|
| task_acq | 5 | 4096 | 100ms | 采集电压/电流/温度 |
| task_prot | 6 | 4096 | 100ms | 保护逻辑（过压/欠压/过流/过温/热失控） |
| task_soc | 4 | 4096 | 1000ms | SOC/SOH 估算（AEKF + 安时积分） |
| task_comm | 2 | **8192** | 1000ms | MQTT 上报/命令/参数/影子（2026-08-08 由 4096 修复栈溢出） |
| task_bal | 3 | 2048 | 10000ms | 均衡控制 |
| task_oled | 1 | 4096 | 100ms | OLED 显示/按键菜单 |
| task_sd | 1 | 4096 | 1000ms | SD 黑匣子记录 |
| task_ota | 1 | 8192 | — | OTA 升级 |
| task_alarm | 5 | 2048 | 100ms | 声光报警 |
| task_wdt | 7 | 1024 | 1000ms | 看门狗 |

### 3.2 云端（华为云 IoTDA）

- 设备: `<IOTDA_DEVICE_ID>_BMS001`，HMAC 动态鉴权（Password = HMAC-SHA256(密钥, 时间戳)，时间偏差 >5min 会认证失败）
- 物模型: 产品 `BMS_DEVICE_BMS_BMS-V1`，在线 JSON **22 属性 + 11 命令 + 1 事件**（2026-08-10 复核：`iotda_product_model.json` 实测 22 属性，含新补 crc/crc32；离线 V2 包 50 属性/10 命令/3 事件）
- 上报 topic: `$oc/devices/{id}/sys/properties/report`
- 命令下发: `$oc/devices/{id}/sys/commands/request_id={rid}`（固件同时监听 `messages/down`）
- 影子: 平台保存设备最新上报属性，Dashboard 轮询影子获取数据

### 3.3 服务层（tools/dashboard/）

| 模块 | 文件 | 职责 |
|------|------|------|
| Flask 后端 | app.py | 登录/RBAC/API/SocketIO/OTA/报表/CSV导出（约 1840 行） |
| 数据库 | database.py | SQLite: bms_data 历史表 / audit_log 审计 / users 用户表 |
| 华为云客户端 | iotda_client.py | REST 影子轮询（分级轮询 10s~900s）/ 命令下发 / HMAC 签名 |
| MQTT 客户端 | mqtt_client.py | 调试用 MQTT 直连客户端 |
| 前端 | frontend/static/app.js + frontend/templates/ | 仪表盘/曲线/控制/报表（约 4300 行 JS，含智能日期标签） |
| 守护 | scripts/watchdog.ps1 + scripts/*.bat | 180s 健康检查自动重启 + 开机自启 |

**REST API 一览**：`/api/status`(3s缓存) `/api/history` `/api/faults` `/api/refresh` `/api/debug/shadow` `/api/diag` `/api/cmd` `/api/params`(GET/POST) `/api/export.csv` `/api/report` `/api/soh_trend` `/api/audit_log` `/api/devices` `/api/ota/*` `/login` `/logout`

**数据库表**：`bms_data`（19+ 字段，含 c1~c6/cells_json/charge_mos 等）、`audit_log`（命令审计）、`users`（多用户 RBAC：admin/operator/viewer）

### 4.4 SOC/SOH 算法（2025-2026 前沿）

| 方法 | 说明 | 本项目现状 |
|------|------|------------|
| 安时积分 + OCV 多项式校正 | 基础方法 | ✅ 已实现（OCV 三次多项式 + 二分法反查） |
| 自适应扩展卡尔曼滤波 (AEKF) | 主流方法 | ✅ 已实现（默认算法，R0/R1/R2 二阶 RC + Sage-Husa 自适应） |
| **最大相关熵 EKF (MCC-EKF)** | 2025 Energy 自适应核宽 MCCEKF / 2025 西安交大 GMMCC-EKF，非高斯噪声下精度提升 47~90% | ✅ **已实现**（2026-08-09：`soc_algo=3`，高斯核加权 R_eff 抗野值） |
| **无迹卡尔曼 (UKF)** | 2026 FOMIUKF（误差 0.78%）/ NDO-UKF / 2026 Sci.Rep OCV-UKF，无需求雅可比、sigma 点传播非线性 | ✅ **已实现**（2026-08-09：`soc_algo=4`，7 个 sigma 点 + Cholesky） |
| IEKF（不变扩展卡尔曼） | 2025：初始值不准时快速收敛 | ❌ 未实现（UKF 已覆盖主要收益） |
| DNN-N-BEATS / 数据驱动+模型混合 | 2025 前沿，动态工况下误差 <1% | ❌ 未实现（需训练数据与算力，嵌入式暂不现实） |

> 2026-08-09：SOC 算法已从 1 种扩展为 **4 种可配置**（AEKF/纯积分/OCV查表/MCC-EKF/UKF，共 5 档），网页 `soc_algo` 下发即实时切换，多串数自适应。

**延迟链路排查结论**：

1. **传输延迟 ≈ 0s**：`bms_data` 中 `timestamp`（设备毫秒）与 `recv_time`（后端秒）换算后完全一致，EMQX 腿为实时传输，非延迟来源。
2. **延迟主要来自上报周期**：固件 `report_interval_sec` 默认 10s（最小 7s，网页可调），前端看到的数据天然滞后 0~10s。
3. **前端刷新**：SocketIO websocket 实时推送（低时延）+ `/api/status` 3s 短缓存 + 15s comm 轮询兜底；websocket 断开时降级轮询（10~15s）。
4. **华为云影子腿**：后端 iotda_client 分级轮询（在线 5s / 故障 5s / 离线 10s~120s），非实时路径。

**连接路径（待确认后锁定）**：bms01 peername=116.169.4.116（公网 IP）→ 疑似直连 ECS:8083 明文 ws（安全组按来源放行），而非 cloudflared 隧道（隧道 127.0.0.1 连接存在但未承载 bms01）。已记录，下一步可评估切回 wss 隧道加密。

### 5.5 双速率双通道架构（2026-08-18 实现）

**目标**：EMQX 为主通道（100ms 高频实时），华为云为备用通道（7s 全量兜底），全程加密。
