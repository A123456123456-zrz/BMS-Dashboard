## 2. 标准对标差距（对照 2025-2026 最新资料）

| 标准 | 2025-2026 动态 | 本项目差距 |
|------|----------------|-----------|
| GB/T 38661-2020 | **2026-01 复审结论=修订，新版本 20260594-T-339 正在起草** | 需跟踪新版修订内容（精度/功能要求可能加严） |
| QC/T 1264-2025 | **2025 发布：动力电池管理系统模拟前端芯片技术要求及试验方法** | 与本项目 LTC6804 直接相关——应核对 AFE 芯片试验方法（精度/EMC/诊断） |
| T/GDBIA 09-2025 | 2025-08 发布：低速电动车锂电池 BMS 通用技术规范 | 若走低速/储能市场可对标 |
| ISO 26262 | ASIL-D 成为车规 AFE 标配 | 当前文档按 SIL2（≈ASIL-B）设计，未达 ASIL-D |
| GB 38031-2020 | 电池包安全要求 | 系统级安全测试未做 |

**结论**：硬件层面（精度/诊断）与标准差距不大，主要差距在**绝缘检测、功能安全认证、型式检验**三项。

## 3. 硬件扩展提升（对比最新 AFE 资料）

### 3.1 AFE 芯片换代建议

> 检索资料：ADI AFE 代际演进——LTC6811（LTC6804 引脚兼容升级版）→ LTC6813（18节）→ ADBMS6815（ASIL-D）→ ADBMS6830/6832/6834（同步采样、以太网）。

| 方案 | 优点 | 代价 | 建议 |
|------|------|------|------|
| **LTC6811**（替换 LTC6804） | **引脚兼容直换**，内置放电定时器、ISO 26262 诊断增强，±1.2mV 不变 | 价格略高 | ⭐ 首选：改动最小，软件适配小 |
| LTC6813 | 18 节/芯片，被动均衡 200mA | 需改 PCB/驱动 | 扩 16S 时考虑 |
| ADBMS6830/6832 | 真正同步采样、ASIL-D、平台化 | 驱动重写、成本高 | 企业级/车规目标 |
| ADBMS6834 | 10BASE-T1S 车载以太网 | 生态重 | 远期 |

### 3.2 系统硬件扩展

| 方向 | 内容 |
|------|------|
| 多串化 | 1~32S 自适应：软件全链路已就绪（运行时串数），**BSP 多芯片驱动已实施**（2026-08-09：16S=2片/24S=2片/32S=3片，方案A 共享 SPI2+独立片选，非菊花链）；接线 + 改 `LTC6804_CHIP_NUM` 即可扩串 |
| 绝缘检测 | 添加绝缘电阻检测电路（母线→地，分时注入） |
| 预充回路 | 预充继电器 + 限流电阻，上电时序控制 |
| 电流采样升级 | 隔离式电流传感器（磁通门/隔离放大器），提升共模抑制 |
| 均衡升级 | 主动均衡（能量转移），当前被动均衡 30mV 阈值只能慢平衡 |
| 双电源冗余 | 主控双供电（电池降压 + 外部），掉电自持 |

## 4. 软件算法提升（对比 2025-2026 前沿）

### 4.1 SOC 算法（现状 → 已落地 → 待升级）

| 方法 | 对比说明（2025-2026 论文） | 状态 |
|------|----------------------|------|
| AEKF（二阶 RC） | 基础可靠，V_meas=0 时退化为安时积分 | ✅ 基线（`soc_algo=0`，默认） |
| **MCC-EKF**（最大相关熵 EKF） | 2025 Energy 自适应核宽 MCCEKF / 西安交大 GMMCC-EKF：非高斯噪声下精度提升 47~90%，对测量野值鲁棒 | ✅ **已实现**（`soc_algo=3`，高斯核加权 R_eff 抗野值） |
| **UKF**（无迹卡尔曼） | 2026 FOMIUKF（误差 0.78%）/ NDO-UKF / 2026 Sci.Rep OCV-UKF：无雅可比、sigma 点传播非线性 | ✅ **已实现**（`soc_algo=4`，7 sigma 点 + Cholesky，float32 安全参数） |
| IEKF（不变扩展卡尔曼） | 2025：初始值不准时仍快速收敛 | ⬜ 未做（UKF 已覆盖主要收益） |
| 多尺度自适应 UKF | 2025：微/中/宏观多时间尺度，动态工况 RMSE 低 | ⬜ 未做（可在 UKF 基础上扩展） |
| DNN-N-BEATS / 数据驱动混合 | 2025：动态工况误差 <1%，但需训练数据 | ⬜ 未做：需先积累云端数据与算力 |

### 4.2 其他算法

| 方向 | 内容 |
|------|------|
| SOH 升级 | 容量法（实测 Ah）+ 内阻法融合，当前仅放电安时累计 |
| RUL 预测 | 基于历史数据的剩余寿命预测（AI） |
| 均衡策略优化 | 容量差均衡（BQ34Z100 电量计辅助）替代纯压差 |
| 故障预测 | 基于趋势的早期故障预警（温升/内阻漂移） |

## 6. 优先级路线图（建议执行顺序）

### P0 —— 补齐核心功能（1-2 周）
1. **烧录新固件**（2026-08-10 已编译验证 bms.bin，含 H1~H20 修复：HMAC 鉴权/看门狗/离线缓存/OTA 等）→ `idf.py -p COM口 flash` 解决设备重启与鉴权失败
2. 接 LTC6804 + 温度 NTC → 电压/SOC/温度恢复显示（SPI 半双工 bug 已修 H6）
3. 接充/放电继电器 → 保护动作可执行、远程通断可用（接线时加驱动管栅极上拉电阻，H16）
4. 接 BQ34Z100 电量计（宏已=1）→ SOC 交叉验证（读协议 bug 已修 H7）

## 7. 一句话总结

> **最优先**：烧录新固件 + 接 LTC6804/继电器（把"欠账"还清，系统成为完整可用 BMS）。
> **其次**：绝缘检测 + 告警推送 + SOC 算法升级（对标 2025 最新资料可做，性价比高）。
> **长期**：AFE 换代 + 功能安全认证（走向企业级）。
