# BMS-C1 仿制适配方案（说明书第 11 篇）

- 版本: v2.0 | 日期: 2026-08-25
- 目标: 以 **ESP32-S3 最小系统板** 为主控，**全仿** LibreSolar **BMS-C1**（参考仓库：`D:\bms设计参考资料\bms-c1-main`）硬件设计，软件按 C1 硬件逐项对齐。
- 核心原则: **功能网络不变，引脚按新板走线重连** —— 引脚改动集中在 `bms_pinmap.h`；驱动接口保持，上层业务逻辑零改动。
- v2.0 变更: 深挖 C1 原理图/PCB/BOM/官方固件，完成**原理图核对**、**BQ76952 初始化配置写回**、**温度直读**、**RS485 分脚**适配。

## 2. 硬件设计核对结论（v2.0 新增）

### 2.1 原理图 / PCB / BOM 三方一致 ✅

对 `pcb资料/新建文件夹/`（KiCad 9 工程）做了位号级三方对比：

| 数据源 | 器件数 | 结论 |
|--------|--------|------|
| 原理图（5 张 .kicad_sch 合并） | **209** | 位号集合与 PCB **完全一致**（comm 差集为空） |
| PCB（bms-c1.kicad_pcb） | **209** | — |
| 官方 BOM（build/bms-c1_bom.csv） | **209** | 无 DNP 选贴件；器件与 PCB 一致 |

**结论：仓库内的原理图与板子是匹配的，没有"缺器件"。** 你观察到的差异很可能来自**版本**：

- 仓库同时含 **v0.3 / v0.4** 两版（`bms_c1_0_3_0.overlay` vs `bms_c1_0_4_0.overlay`）
- 两者 **I2C 引脚不同**：v0.3 = GPIO6/7；v0.4 = GPIO8/9；**RS485 已改为 TX=GPIO14/RX=GPIO21，DE/RE 短接共用 GPIO47（2026-08-26 更新）**
- 若手上实物按 v0.3 打样，就会与当前原理图（v0.4）"对不上"

### 2.3 BQ76952 引脚功能配置（C1 DTS 权威值，已写入固件）

| 项 | C1 配置 | 说明 |
|----|---------|------|
| 地址 | `0x08` | ADDR 接法 |
| used-cell-channels | `0xFFFF` | 16S 全用 |
| TS1/TS3 pin-config | `0x07` | **NTC thermistor 模式（内部 18k 上拉）** → 温度命令返回 0.1K |
| DCHG pin-config | `0x0F` | **FET 温度 ADC 输入**（fet-temp-pin=DCHG） |
| DFETOFF pin-config | `0x07`（v0.4） | **分流温度 NTC**（shunt-temp-pin=DFETOFF） |
| shunt | `300µΩ`，board-max-current `100A` | 库仑计/过流换算基准 |
| auto-pdsg | 启用 | 自动预放电 |

## 3. 引脚映射（新板）

> **结构（2026-08-25 确认）**：S3 最小系统板通过排针插入仿 C1 PCB 上的排母座，电源与信号全部经排针互联，**整体算一块板**（详见说明书 02 篇 §2.5 板间排针接口）。
> 新板可用引脚 = U4/U6 排针引出 GPIO：**GPIO0~21 + GPIO35~48**（G22~G34 未引出）。
> S3 约束：strapping=G0/G3/G45/G46，USB-JTAG=G19/G20，UART0=G43/G44，JTAG=G39~G42。

| 功能 | 新板引脚 | C1 参考 | 说明 |
|------|----------|---------|------|
| I2C SDA | **GPIO8** | GPIO8 | BQ76952（与 C1 v0.4 及原工程一致） |
| I2C SCL | **GPIO9** | GPIO9 | BQ76952（地址 0x08） |
| BQ76952 WAKE | **-1（禁用）** | 无 | C1 无 WAKE，依赖 I2C 自唤醒 |
| TWAI TX（CAN） | **GPIO5** | GPIO5 | SN65HVD230 D 输入 |
| TWAI RX（CAN） | **GPIO4** | GPIO4 | SN65HVD230 R 输出 |
| CAN STB | **GPIO48** | GPIO10 | 待机（低=正常，2026-09-07 改） |
| RS485 TX | **GPIO14** | — | UART1 via GPIO matrix；避开 USB 占用的 GPIO20 |
| RS485 RX | **GPIO21** | — | UART1 via GPIO matrix；同上 |
| RS485 DE/RE | **GPIO47** | GPIO47（短接） | DE/RE 短接共用，高=发送，低=接收 |
| LED 红 | **GPIO1** | GPIO1 | 保护/严重 |
| LED 绿 | **GPIO2** | GPIO0（S3 上为 strapping，避开） | 正常 |
| 按键 | **GPIO0** + **GPIO13** | GPIO3 | 板载 BOOT 键（active-low，翻页/复位/配网）+ **SW_PWR 电源键 GPIO13**（高有效，长按 3s 关功率，2026-08-25 新增；S3 的 GPIO3 是 strapping，不能当按键） |
| USB-JTAG | GPIO19/20 保留 | — | COM6 烧录口，不可占用 |
| UART0 | GPIO43/44 保留 | — | RX0/TX0 调试 |

**未占用空闲引脚**：GPIO11~15、18、21、35~42、47、48（共 17 个，供扩展）。

### 4.1 本次深挖新增（v2.0）

- **`bsp_bq76952_read_temp()`**：TS1~TS3 温度命令（0x70/0x72/0x74）返回 0.1K，换算为 0.1℃（与 LTC6804 方案 `bsp_temp_calc_dc` 输出单位一致）。C1 的 TS 是 thermistor 模式（18k 上拉 NTC），**直接读温度**，不再走 mV→NTC 换算。
- **`bsp_bq76952_apply_config()`**：进入 CFGUPDATE（0x0090）→ 写回 TS1/TS3=0x07、DCHG=0x0F、DFETOFF=0x07、VCELL_MODE=16S 差分 → 退出（0x0092）。协议与 Zephyr `datamem_write_u1` 一致（0x3E/0x3F 地址 + 0x40 数据 + 0x60 校验和）。失败仅告警不阻塞（出厂可能已配置）。
- **RS485 DE/RE 短接**：DE/RE 共用 GPIO47，高=发送，低=接收（2026-08-26 简化，不再分脚）。

## 5. 软件-硬件匹配要点（核对结论）

- ✅ **BQ76952 地址 0x08**、**TS1/TS3 thermistor 18k**、**DCHG=FET 温度**、**DFETOFF=分流温度**（v0.4）、**16S 差分** —— 均已写回固件。
- ✅ **温度读取**：TS 命令直读 0.1K→0.1℃，与 C1 硬件 NTC 配置匹配（原 mV 换算方案已弃用）。
- ✅ **电流方向**：CC2 正=放电、负=充电，与旧 INA181 一致，上层判断无需改。
- ✅ **FET bit 定义**：FET_CONTROL(0x0097) bit0=DSG、bit3=CHG（TI E2E + TRM Table 12-29）。
- ✅ **I2C 总线**：由 `bsp_bq76952_init` 初始化（幂等）；`bsp_oled_init` 不再重复初始化，OLED(0x3C) 与 BQ76952(0x08) 并联同一总线，必须在 BQ76952 init 之后调用。
- ✅ **CAN**：SN65HVD230 STB 低=正常（GPIO10），与 C1 一致。
- ✅ **RS485**：SN65HVD75 DE/~RE 分脚，与 C1 v0.4 原理图（RS485_DE / RS485_~RE）一致。
- ✅ **LED/按键避 strapping**：S3 上 GPIO0/GPIO3 是 strapping，绿灯用 GPIO2、按键用 GPIO0 BOOT 键（C1 的 GPIO0 绿灯/GPIO3 按键在 S3 不可用，属合理偏移）。

## 6. 遗留风险 / 待确认项（新板打样/接线时核对）

| # | 风险/待确认 | 说明 |
|---|-------------|------|
| 1 | **实物板版本** | 若实物是 v0.3（I2C=GPIO6/7）而非 v0.4（GPIO8/9），需在 `bms_pinmap.h` 改回并确认 BQ76952 地址 |
| 2 | ~~ALERT 中断~~ ✅ **已接** | 2026-08-25 已按 C1 接入：ALERT=**GPIO12**（C1 原 GPIO2 被 LED 绿占用，故用空闲脚），开漏+10k 上拉、高有效，`bsp_bq76952_init` 配置上升沿中断置标志，采集任务轮询双保险（`bsp_bq76952_alert_pending`） |
| 3 | ~~按键极性~~ ✅ **已适配** | C1 的 SW_PWR(GPIO3 高有效) 已用 **GPIO13 独立电源键**实现（`bsp_sw_pwr.c`：长按 3s 关 FET 功率，对齐官方 button_pressed_for_3s→shutdown）；BOOT 键(GPIO0 低有效)保留 UI 功能；GPIO3 是 strapping 未用 |

| 7 | **TWAI 收发器供电** | SN65HVD230 为 3.3V 器件，确认供电与电平匹配（旧 TJA1050 5V 教训） |
