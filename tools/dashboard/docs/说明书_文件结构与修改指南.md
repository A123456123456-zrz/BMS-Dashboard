# BMS Dashboard 说明书(本地部署版)

> 适用场景:你的电脑 = 数据库 + 服务器 + 后端(2026-08-12 起,阿里云 ECS 已停用)
> 数据链路:`ESP32 → 华为云 IoTDA(MQTT 接入层)→ 本机 Dashboard(IoTDA REST 轮询)→ 浏览器`

---

## 一、整体架构

```
ESP32(BMS001) ──MQTT/TLS──▶ 华为云 IoTDA(接入层)
                                   │  REST API(轮询设备影子)
                                   ▼
你的电脑(本机) ◀── bms_history.db(SQLite 数据库)
    │
    ├─ Flask 后端(backend/app.py, 监听 0.0.0.0:5000)
    ├─ 前端页面(frontend/, 由 Flask 渲染)
    ├─ cloudflared 隧道(config.yml → 公网 http://<YOUR_ECS_IP>:5000)
    └─ watchdog.ps1(守护进程: 自动拉起/重启 后端与隧道)
```

- 浏览器访问 **`http://<YOUR_ECS_IP>:5000`**(公网)或 **`http://localhost:5000`**(本机)
- 登录密码:**`bms123`**
- 设备接入配置见固件侧 `components/bms_config/include/bms_config.h`(本说明书不展开)

## 四、日常操作速查

### 启动 / 停止
- **启动**(推荐):双击 `scripts/start_dashboard.vbs`,或运行 `wscript scripts/start_dashboard.vbs`
- **开机自启**:管理员运行 `scripts/install_autostart.bat`(之后每次登录自动启动)
- **停止**:任务管理器结束 `python.exe(app.py)` / `cloudflared.exe` / `powershell.exe(watchdog)`

### 修改后的生效方式
| 改了哪 | 怎么生效 |
|---|---|
| 前端(`frontend/`) | 浏览器 **Ctrl+F5** 硬刷新即可(无需重启) |
| 后端(`backend/*.py`、`dashboard.env`) | 重启后端:任务管理器杀 python,再双击 `scripts/start_dashboard.vbs` |
| 隧道(`tunnel/config.yml`) | 重启 cloudflared 或整机重启 |
| 固件(ESP32 侧) | 见下方编译步骤 |

### 编译固件(ESP32)
在项目根目录(Git Bash)执行(**必须用这条,export.sh 不支持 MSys**):
```bash
cmd //c "set MSYSTEM=& set PATH=C:\Espressif\python_env\idf5.2_py3.11_env\Scripts;%PATH% & call D:\v5.2.7\esp-idf\export.bat >nul 2>&1 & idf.py build"
```
- 产物:`build/bms.bin`
- 烧录:`idf.py -p COM6 flash`(设备在 COM6)
- 常用改动的文件:
  - `components/bms_config/include/bms_config.h` — MQTT 地址/设备ID/密钥/OTA 地址
  - `components/bms_middleware/sys_mqtt.c` — MQTT 接入逻辑
  - `components/bms_middleware/sys_wifi.c` — WiFi/DNS(2026-08-12 已加静态 DNS 兜底 223.5.5.5/8.8.8.8)

## 五、常见问题

| 症状 | 原因/处理 |
|---|---|
| 公网 `bms0605.dpdns.org` 打不开(530/502) | 本机后端或隧道没起来 → 双击 `scripts/start_dashboard.vbs`;或看 `logs/watchdog.log` |
| 本机 `localhost:5000` 打不开 | 后端没起来 → 看 `logs/app.stdout.log`;锁文件残留 → 删 `logs/.bms_dashboard.lock` 再启 |
| 重启电脑后网页进不去 | 需登录后自启;重装自启用 `install_autostart.bat`(管理员) |
| 设备(ESP32)连不上华为云,日志 `getaddrinfo 202` | DNS 问题,已加静态 DNS 兜底,需**重新烧录最新固件**;也可在路由器把 DNS 改为 223.5.5.5 |
| 设备报 `mqtt_ret=4`(认证失败) | NVS 残留旧凭据 → 配网页(192.168.4.1)重新填真实密钥;或 `idf.py erase-flash` 后重配 |
| 页面显示离线/无数据 | 检查设备是否在线 + 本机后端轮询是否正常(`app.stdout.log`) |

## 六、修改示例(3 个高频需求)

1. **改登录密码**:编辑 `backend/dashboard.env` 中 `BMS_DASH_PASSWORD=...` → 重启后端
2. **改网页标题/主题色**:`frontend/templates/index.html` 的 `<title>` + `frontend/static/style.css` 的 `--primary` 等变量 → Ctrl+F5
3. **改 OTA 升级地址**:固件 `components/bms_config/include/bms_config.h` 的 `BMS_OTA_VERSION_URL` → 重新编译烧录
